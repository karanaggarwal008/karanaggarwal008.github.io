This repository houses the personal portfolio and digital garden of Karan Aggarwal, built as a static multi-page site hosted on GitHub Pages. Moving away from generic resume templates, it functions as an interactive archive spanning research papers, student enterprises, venture pitches, writing, and current studies.

The design philosophy draws inspiration from modern editorial portfolios, adopting a bento-grid minimalism similar to Shivansh Gupta's newsletter style and the clean whitespace seen in Akshat Bhaskar's work. It aims for understated credibility, allowing achievements to speak for themselves without aggressive self-promotion, while blending clean typography with interactive storytelling in the spirit of Aneeket Das. The visual identity relies entirely on a trustworthy light color palette featuring warm sand, muted terracotta, and soft sage accents to maintain a calm, intellectual aesthetic.

The site structure is organized into dedicated pages including an entry landing bento grid, an exploration record, venture case studies on build projects like Deepshikha, current commitments and studies, academic research dossiers, recognition and awards, media mentions, a full curriculum vitae, verified credentials, and original writing updates.

Moving away from standard template resume sites, the project serves as an interactive and narrative-driven archive covering research papers, student enterprises, venture pitches, writing, and current academic studies.

The design philosophy relies on a bento-grid minimalism inspired by modern editorial portfolios, drawing structural rhythm from newsletter-style layouts and minimalist whitespace frameworks. It uses a calm, trustworthy light color palette featuring a warm sand base, muted terracotta, and soft sage accents to maintain high readability and an intellectual aesthetic. Paired with clean typography using DM Sans and Instrument Serif, the site incorporates micro-interactions to create an engaging and understated showcase of achievements.

The directory structure is organized into dedicated HTML pages including an overview landing page, exploration logs, venture case studies, current commitments, research dossiers, recognition records, media appearances, a formal curriculum vitae, verified credentials, and original journal writing.

The home landing page opens with an authentic human voice and a bento grid providing quick-entry points to major milestones, such as a World Finance and Banking Symposium research acceptance, Deepshikha student business leadership metrics, HPAIR Asia Conference recognition, and LaunchX pitch awards. Meanwhile, the current focus page tracks simultaneous institutional commitments without cluttering the main resume, capturing academic pursuits at IIM Bangalore, Company Secretary registration with ICSI, CFA Level I candidate preparation, the Aspire Leaders Program fellowship, and ongoing research and editorial responsibilities.

Technically, the site is constructed using native CSS Grid and Flexbox with responsive media queries for mobile and desktop navigation. The contact drawer leverages modern HTML popover attributes for lightweight interactive panels, while asynchronous Google Fonts preloading ensures rapid performance on static hosting. Maintenance is kept straightforward, running locally via a simple static server and deploying directly to GitHub Pages upon pushing to the main branch.
